# Архив исходников

Архив не является частью пайплайна. Импорт `src.legacy` намеренно запрещён.

- `processing/`: прежняя плоская структура Python-модулей до PR #4.
- `previous_layout/`: снимки файлов перед текущим переносом, для сравнения поведения.
- `tests/`: исторические самостоятельные проверки, включая устаревшие ожидания.

Архив не содержит учебных CSV и не собирается pytest. Рабочие реализации
находятся только в тематических подпакетах `src/processing`.
