# COMETKiwi: оценка окон выравнивания

Каждая запись Vecalign становится центром окна: предыдущая группа + центр +
следующая группа. Это группы, а не фиксированное число предложений. На краях
документа окно сокращается. Для каждой стороны предложения соединяются пробелом
в исходном порядке. Используется `normalized_text` из нормализованных JSON.

Модель оценивает **всё окно**, не только центральную запись. Балл выше обычно
означает лучшее качество, но не является вероятностью правильности. Текстового
объяснения ошибки стандартный COMETKiwi не возвращает; MQM-анализ выполняется
отдельно. Перекрывающиеся окна не являются независимыми наблюдениями: среднее
их баллов не следует выдавать за стандартную оценку COMET всего документа.

## Установка и модель

В окружении, которым запускается приложение:

```powershell
python -m pip install -r src/processing/evaluation/requirements.txt
```

По умолчанию используется `Unbabel/wmt22-cometkiwi-da`, CPU, батч 8. Модель
загружается один раз на задачу, затем используется для всех выбранных переводов.
Первая загрузка получает checkpoint; следующие используют кэш библиотеки.
Проверьте условия доступа/лицензию выбранной модели на Hugging Face. При
необходимости авторизуйтесь локально через `hf auth login` после принятия условий.
Токены не записываются в JSON результатов или настройки приложения.

На странице «Оценка перевода» можно сохранить имя модели либо путь к уже
скачанному COMETKiwi `.ckpt`, размер батча и выбор GPU. Настройки находятся в
`data/cometkiwi_settings.json`; они применяются к следующему запуску UI и main.
Если настройки отсутствуют, модель можно задать переменной `COMETKIWI_MODEL`.
Нужна именно модель QE/COMETKiwi, работающая без эталонного `ref`.

## Запуск

Отдельный этап на существующих нормализованных предложениях и `.align`:

```powershell
python -m src.processing.main --stage cometkiwi
python src/processing/main.py --stage cometkiwi
```

Этап также включён в полный пайплайн после выравнивания слов. Сам COMETKiwi
не использует результаты SimAlign, поэтому его можно запускать отдельно сразу
после Vecalign. В UI есть кнопка этапа и страница просмотра результатов.

Произвольные имена файлов, без реестра документов приложения:

```powershell
python -m src.processing.evaluation.io --source data/normalized/book-ru.json --target data/normalized/book-en.json --alignment data/aligned/book.align --output data/translation_quality/book.cometkiwi.json --model Unbabel/wmt22-cometkiwi-da --batch-size 8 --gpus 0 --radius 1
```

Для внедрения уже загруженной модели:

```python
from src.processing.evaluation.cometkiwi import CometKiwiBackend
from src.processing.evaluation.io import evaluate_files

backend = CometKiwiBackend(preloaded_model, model_name="my-cometkiwi")
evaluate_files(source_path, target_path, alignment_path, output_path, backend=backend)
```

`build_windows` и `evaluate_windows` не читают и не записывают файлы. Их можно
использовать напрямую с документами и внедрённым адаптером модели.

## Результат

По умолчанию создаётся один файл на пару:
`data/translation_quality/original-rus_<перевод>.cometkiwi.json`.

- `model`: модель, checkpoint, параметры, направление и область оценки.
- `inputs`: пути и SHA-256 входных файлов, плюс время создания результата.
- `windows`: центр, номера соседних групп, индексы/идентификаторы/тексты
  предложений обеих сторон, точные исходные строки Vecalign и их стоимости.
- `verdict`: `status`, `score`, `scope: entire_window`.
- `summary`: количество окон каждого статуса.

Статусы: `scored`, `empty_side`, `too_long`. При пустой стороне всего окна модель
не вызывается. Пропуск внутри непустого окна сохраняется в составе и отмечается
`alignment_gap_present`; оценка не отменяет необходимость проверки пропуска.
Длинные окна отмечаются `too_long` с количеством токенов, без незаметного
обрезания. Входное выравнивание обязано полностью и монотонно покрывать документы.
Результат записывается атомарно после успешной обработки, входы не перезаписываются.

Окна пересекают границы абзацев/глав, если такие границы не представлены отдельным
ограничением входного выравнивания: автоматическое распознавание глав не выполняется.
